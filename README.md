# SEO Start

Курс базового SEO українською: 41 короткий урок-інструкцію у трьох блоках. Приклад у всіх уроках: сайт бюро перекладів «Мости», mosty.com.ua.

1. **Новий сайт: GitHub + Vercel** (18 уроків): індексація, URL і коди, ключові слова (Keyword Planner, Trends, Serpstat), кластеризація, конкуренти (GS Location Changer, Serpstat, Ahrefs), структура, текст посадкової, GitHub, Vercel, SEO-теги, мікророзмітка schema.org, hreflang, robots.txt, sitemap, Search Console, GA4 через GTM, діагностика індексації, Google Business Profile.
2. **Аудит і виправлення: WordPress** (17 уроків): доступи і бекап, код сторінки, Screaming Frog, Netpeak Spider, чек-лист аудиту, редиректи, HTTPS і змішаний вміст, дублікати і canonical, noindex, налаштування WordPress, Rank Math і Yoast, плагіни, звіт «Сторінки», швидкість, on-page масово, внутрішні і зовнішні посилання, правила Google.
3. **Аналітика і звіти** (5 уроків): Search Console, GA4, позиції в Serpstat, звіт керівнику, пошук причини падіння трафіку.

Кожен урок: відеорозбір-схема з озвучкою, що це і навіщо, куди натискати, приклад, типові помилки, чек-лист, конспект, тест з пʼяти питань з полем «Чому я так вважаю».

## Мовні версії

Українська: `/`, англійська: `/en/`, польська: `/pl/`. На кожній сторінці hreflang (uk, en, pl, x-default), canonical і перемикач мови. Мовні версії також є в `sitemap.xml`.

## Як відкрити

Двічі клацніть `index.html`. Усі файли мають лежати в одній папці.

## Файли

| Файл | Що в ньому |
|---|---|
| `index.html` | українська сторінка курсу; без `#` в адресі відкривається вітальна сторінка |
| `logo.svg`, `favicon.svg` | логотип SEO Start і іконка вкладки |
| `logos/` | три варіанти логотипа (обрано третій) |
| `app.js`, `app.css` | двигун і дизайн, спільні для всіх мов |
| `en/`, `pl/` | англійська і польська версії (уроки і схеми) |
| `sitemap.xml`, `robots.txt` | карта сайту з hreflang і правила для роботів |
| `c1.js` | уроки Блоку 1 |
| `c2.js` | уроки Блоку 2 |
| `c3.js` | уроки Блоку 3 |
| `c4.js` | додаткові уроки (мікророзмітка, hreflang, HTTPS та інші) |
| `ill.js` | схеми-ілюстрації |
| `old.js` | матеріали попередньої версії: довші відеорозбори, конспекти, схеми, додаткові питання тестів |
