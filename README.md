# SEO Старт

Курс базового SEO українською: 41 короткий урок-інструкцію у трьох блоках. Приклад у всіх уроках: сайт бюро перекладів «Мости», mosty.com.ua.

1. **Новий сайт: GitHub + Vercel** (18 уроків): індексація, URL і коди, ключові слова (Keyword Planner, Trends, Serpstat), кластеризація, конкуренти (GS Location Changer, Serpstat, Ahrefs), структура, текст посадкової, GitHub, Vercel, SEO-теги, мікророзмітка schema.org, hreflang, robots.txt, sitemap, Search Console, GA4 через GTM, діагностика індексації, Google Business Profile.
2. **Аудит і виправлення: WordPress** (17 уроків): доступи і бекап, код сторінки, Screaming Frog, Netpeak Spider, чек-лист аудиту, редиректи, HTTPS і змішаний вміст, дублікати і canonical, noindex, налаштування WordPress, Rank Math і Yoast, плагіни, звіт «Сторінки», швидкість, on-page масово, внутрішні і зовнішні посилання, правила Google.
3. **Аналітика і звіти** (5 уроків): Search Console, GA4, позиції в Serpstat, звіт керівнику, пошук причини падіння трафіку.

Кожен урок: відеорозбір-схема з озвучкою, що це і навіщо, куди натискати, приклад, типові помилки, чек-лист, тест з трьох питань.
