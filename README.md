# SEO Старт

Курс базового SEO українською: 52 уроки у трьох блоках.

1. **Новий сайт з нуля**: як Google індексує сторінки, URL і коди відповіді, Search Console, GA4, GTM, Screaming Frog, Netpeak Spider, конкуренти, семантичне ядро, структура, GitHub Pages, robots.txt, noindex, canonical, дублікати, sitemap, hreflang, аудит, перелінковка, on-page, off-page.
2. **Виправлення існуючого сайту**: доступи і бекап, код сторінки, WordPress, Rank Math і Yoast, плагіни, редиректи, HTTPS, звіт індексації, Core Web Vitals, швидкість, зображення, контент-аудит, масові правки, посилання, звіт.
3. **Програми, публікація і звіти**: каталог програм, VS Code, Git і GitHub, Vercel, Serpstat, Ahrefs, Google Trends, DevTools, PageSpeed Insights, GA4, Search Console, позиції, звіт для керівника, пошук помилок.

Кожен урок: відеорозбір-схема з озвучкою і сценарієм, ілюстрація, конспект, покрокова інструкція, чек-лист, тест з трьох питань.

## Як відкрити

Двічі клацніть `index.html`. Усі файли мають лежати в одній папці.

## Файли

| Файл | Що в ньому |
|---|---|
| `index.html` | сторінка курсу: дизайн, плеєр, навігація, прогрес |
| `b1a.js`, `b1b.js`, `b1c.js`, `b1x.js` | уроки Блоку 1 |
| `b2a.js`, `b2b.js` | уроки Блоку 2 |
| `b3a.js`, `b3b.js` | уроки Блоку 3 |
| `ill.js` | схеми-ілюстрації |
| `tests.js` | додаткові питання тестів |

Відмітки в чек-листах і пройдені тести зберігаються в браузері, на якому ви відкрили курс.
